## Reading order

New here: [../README.md](../README.md), then
[architecture.md](architecture.md). The README says what the app does and
how to run it, the architecture shows where the work happens.

Changing the behaviour: [../PRODUCT.md](../PRODUCT.md) for what the current
build promises, [architecture.md](architecture.md) for the code behind it,
then [../AGENTS.md](../AGENTS.md) for the traps. A change that moves the
transcript or the masking has to be written into the product document as
well.
